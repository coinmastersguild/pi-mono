# Pioneer CLI 1.1.3

Install or upgrade with Node.js 22.19 or newer.

```sh
npm install -g @pioneer-platform/pioneer-cli
```

Run `pioneer` to sign in, or use `/login` to replace a saved key. Get your API
key at [Alpha](https://alpha.pioneers.dev/keys), paste it into the masked prompt,
and press Enter. Pioneer verifies the key with Alpha before saving it.

The Pioneer CLI offers Pioneer models, including Auto and any models discovered
through Alpha. Existing Pioneer credentials continue to work. For scripts,
set `PIONEER_API_KEY`.
